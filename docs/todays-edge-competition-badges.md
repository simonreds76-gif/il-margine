# Today's Edge competition badges

Sport filters retain the shared football/tennis icons. Individual picks use their category through the existing MarketBadge component: ATP Tour, Challenger, Grand Slams and football leagues. Dates remain separate; missing categories retain the existing neutral fallback. No new data fetch is introduced.

`public/icons/markets/challenger-tour.png` is the unchanged embedded image from ATP's official 2023 branding exhibit (PDF page 33, image object 230):
https://www.atptour.com/-/media/files/rulebook/2023/2023-atp-rulebook_chapter-10_exhibits-31may.pdf

The Challenger mark is shown on white for contrast, with the readable Challenger category alongside it. Its use identifies the competition; it does not imply ATP endorsement.
